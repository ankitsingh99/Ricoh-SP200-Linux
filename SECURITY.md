# Security Policy

## Supported Versions

We provide security updates and bug fixes for the current `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or security bug in this project:

1. **Do not create a public issue** on GitHub.
2. Please report security issues privately via GitHub's [Private Vulnerability Reporting](https://github.com/ankitsingh99/Ricoh-SP200-Linux/security/advisories/new) or contact the project maintainers directly.
3. Please include the following details:
   - Operating system and version (e.g. Ubuntu 22.04 LTS, macOS 14.5).
   - CUPS version.
   - A step-by-step description to reproduce the vulnerability or exploit.
   - Any relevant logs or stack traces.

We will review your submission promptly and follow up with a fix and advisory.
